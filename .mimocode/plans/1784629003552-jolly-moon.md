# Documentation & Security Review Plan

## Overview
Review and update all documentation for the MallowAndManor project after the Supabase → MongoDB migration. Also flag security issues found.

## Critical Security Findings

### 1. `server/.env` is NOT in `.gitignore` — SECRETS COMMITTED TO GIT
- `server/.env` contains: MongoDB password (`lvPcUrOU4zN9fHRZ`), JWT secrets
- `.gitignore` only ignores `.env` at root, NOT `server/.env`
- **FIX**: Add `server/.env` to `.gitignore`, rotate credentials after push

### 2. JWT secrets are weak/predictable
- `JWT_SECRET=mm_jwt_secret_k8x2m9p4q7w1e5r3t6y0u2i4o8a1s5d3f7g9h2j6k0l`
- These look manually constructed, not cryptographically random
- **RECOMMENDATION**: Generate with `openssl rand -hex 64`

### 3. CORS allows all origins
- `vercel.json` has `Access-Control-Allow-Origin: *`
- Server `index.js` has hardcoded localhost + two Vercel domains

### 4. MongoDB Atlas network access set to `0.0.0.0/0`
- Allows connections from ANY IP worldwide
- **RECOMMENDATION**: Restrict to Vercel's IP ranges
