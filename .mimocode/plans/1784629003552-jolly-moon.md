# Migration Plan: Supabase → MongoDB

## Overview
Full migration of MallowAndManor from Supabase (PostgreSQL + Auth + Storage) to MongoDB Atlas + Express API + Cloudinary for images.

## Tech Stack (New)
| Layer | Choice | Rationale |
|-------|--------|-----------|
| Database | **MongoDB Atlas** (Mongoose ODM) | Already have cluster, schema validation, easy JS integration |
| Backend | **Express.js** | Node ecosystem, Vercel serverless support, simple |
| Auth | **bcrypt + JWT** (access 15min + refresh 7d in httpOnly cookie) | Stateless, no session store needed |
| Image Storage | **Cloudinary** (free 25GB) | Drop-in replacement, auto-optimization, no vendor lock |

## MongoDB Collections
- **categories**: `{ slug, name, icon, createdAt }`
- **products**: `{ name, price, category, mainImage, thumbnails[], description, createdAt }`
- **analytics**: `{ eventType, eventData{}, userAgent, referrer, createdAt }`
- **users**: `{ email, password (hashed), role, createdAt }`

## API Routes
| Method | Endpoint | Auth | Description |
|--------|----------|------|-------------|
| GET | `/api/products` | Public | List all products |
| GET | `/api/products/:id` | Public | Single product |
| GET | `/api/categories` | Public | List categories |
| POST | `/api/analytics` | Public | Track event |
| GET | `/api/analytics/stats` | Public | Product view/cart stats |
| POST | `/api/auth/login` | Public | Login → JWT tokens |
| POST | `/api/auth/refresh` | Cookie | Refresh access token |
| POST | `/api/auth/logout` | Cookie | Clear refresh cookie |
| GET | `/api/auth/me` | JWT | Current user |
| POST | `/api/admin/products` | JWT | Create product |
| PUT | `/api/admin/products/:id` | JWT | Update product |
| DELETE | `/api/admin/products/:id` | JWT | Delete product |
| POST | `/api/upload` | JWT | Upload image → Cloudinary |

## Key Frontend Changes
1. **New `src/lib/api.js`** - fetch-based API client with auto token refresh
2. **`src/App.jsx`** - Replace supabase queries → API calls, map `_id` → `id`
3. **`src/pages/AdminLogin.jsx`** - `login()` instead of `supabase.auth.signInWithPassword()`
4. **`src/pages/AdminDashboard.jsx`** - API for CRUD + `uploadImage()` instead of supabase.storage
5. **`src/pages/AnalyticsDashboard.jsx`** - API for analytics data
6. **`src/pages/ProductDetail.jsx`** - Remove `parseInt(id)`, use string comparison
7. **`src/components/ProductsSection.jsx`** - Sort by `createdAt` instead of `id`
8. **Delete**: `src/lib/supabase.js`, `supabase-complete.sql`
9. **Remove** `@supabase/supabase-js` from dependencies

## Implementation Phases

- Create `server/` directory, package.json, install deps
